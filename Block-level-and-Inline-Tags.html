TAGS IN HTML

In HTML, tags are mainly divide into block-level elements and inline Elements.

1. Block-level Tags: Starts on anewline and usually takes up the full availbale width.

Tag Use
<address> Contact information
<article> Independent article or content
<aside> Related or sidebar content
<section> Defines a section of a webpage
<div> Groups content into sections
<header> Defines the header of a webpage or section
<h1> to <h6> Creates headings
<footer> Defines the footer of a webpage or section
<hr> Creates a horizontal line
<nav> Defines navigation links
<main> Defines the main content of a webpage
<p> Defines a paragraph
<pre> Displays preformatted text
<video> Embeds a video
<ol> Creates an ordered list
<ul> Creates an unordered list
<li> Defines a list item
<dl> Creates a description list
<dt> Defines a term in a description list
<dd> Defines a description in a description list
<form> Creates a form
<table> Creates a table

2. Inline Tags: Do not starts on a new line and only takes up as much as width as necessary.

Tags Uses
<a> Creates hyperlinks
<img> Displays images
<b> Makes text bold
<strong> Shows important text
<i> Displays italic text
<em> Emphasizes text
<u> Underlines text
<mark> Highlights text
<small> Shows smaller text
<sub> Creates subscript text
<sup> Creates superscript text
<big> Enlarges text
<span> Groups inline elements
<q> Shows short quotations
<time> Represents date and time
<label> Labels form controls
<input> Accepts user input
<textarea> Accepts multi-line text
<select> Creates drop-down lists
<button> Creates clickable buttons
<script> Adds JavaScript
<br> Inserts a line break
<hr> Inserts a horizontal line
